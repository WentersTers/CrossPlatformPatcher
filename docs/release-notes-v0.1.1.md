# PAIcom Voice Release v0.1.1 — Release Notes (DRAFT for read-through)

> Status: draft. Product-voice call before publish.

## What this is

One download gives you a voice layer for PAIcom: talk to the game instead
of clicking through menus. Inside the bundle (`PAIcom-Voice-v0.1.1.zip`)
are the Windows patcher, the Linux version, and the virtual-audio driver
installer — no second download. Place the patcher beside `PAIcom.exe` and
run it: it finds the game, sets up what the voice needs, patches a copy
(keeping a backup if you ask), and starts the chain. Say the wake word,
say a command, and the game responds.

This release is unsigned. The Verify section at the bottom shows how to
check your download is genuine.

## Known issues (tracked, not new)

If something below matches what you see, we already know — no need to report it.

- **Pop-ups that keep coming back:** An info pop-up (for example the Discord invite) may appear every time the app starts, even after you dismiss it. Known, being worked on. Dismissing it is safe; nothing breaks.

- **Slow starts and browser-tab bursts on poor connections:** On a slow connection the app can take a while to start, and a voice command may open several browser tabs at once. Known, queued behind the network work.

- **Menu buttons that do nothing:** Some game buttons in the menu do not launch anything when clicked. Expected in this version; game wiring is planned work, not a broken install.

- Mac: there is no Mac download in this release. A Mac version ships after
  Mac testing exists, not before.

## What you need

- Windows 10/11 x64 (for the `.exe`) or 64-bit Linux (for the `.AppImage`),
  with PAIcom installed.
- The patcher takes care of: the VC++ runtime if yours is missing, the
  voice model (included), and the offline speech component (included — if
  it ever crashes, commands still route safely instead of misfiring).
- Virtual audio cable (only needed if you play game audio back into the
  voice input): included as `VBCABLE_Driver_Pack45.zip`, unmodified.
  Extract it, run `VBCABLE_Setup_x64.exe` as Administrator, reboot, and set
  CABLE Output as the default recording device.
  VB-CABLE is donationware by VB-Audio Software — if you find it useful,
  please donate for your license on the VB-Audio webshop.

## Tested, on three operating systems

We tested all 109 voice commands on Linux, Windows 11, and Windows 10.
Every command either did the right thing or safely did nothing — none of
them ran the wrong command. That last part matters: the previous version
could match the wrong command when it misheard the wake word, and that is
fixed here. Recognition quality varies slightly between systems, and it
held up on all three, including the weakest setup we measured.

## Safety check on first run (optional, dismissable)

The first time the patched game starts, a one-time message tells you
whether its files still match the state the patcher left them in. You can
dismiss it forever (deleting the `.tripwire-seen` file next to the game
brings it back), and it never blocks the game.

Plain truth about what it is: a tamper signal for your peace of mind, not
a security boundary. It catches accidental changes, not a determined
attacker.

## How this release was built

- Reproducible builds: rebuilding these sources produces byte-identical
  files, so each hash below proves what source built it (verified by
  building twice and comparing).
- Contents check per release (automatic): the bundle carries only our own
  code, models, and runtimes — a scan confirms no game files inside.
- Tests: 252/252 passing at release time.
